# MacEditor 开发记录

## 用户需求
- 原生 macOS 编辑器，可以编辑代码、Markdown 和纯文本。
- 语法高亮是重点需求（多语言、深浅色配色、增量高亮）。
- 界面语言可以在中文和英文之间切换，切换后立即生效。
- 界面要精致：参考 Nova、Zed、VS Code 的现代风格，内置多套主题。
- 提供 dmg 安装包。
- 源码在 GitHub 公开（Aidan-996/MacEditor）。

## 技术选型
- 用 Swift Package（可执行 target）组织项目，**不使用 Xcode 工程**。用 `swift build` 构建，再用脚本打包 .app 和 dmg。
- 界面用 SwiftUI（DocumentGroup、Settings、Commands），编辑器核心是通过 NSViewRepresentable 包装的 AppKit NSTextView（TextKit 1）。
- 行号栏用 NSRulerView；Markdown 预览用 WKWebView 加内置的 Markdown→HTML 转换器。
- 语法高亮基于正则，先高亮当前行，再防抖做全量高亮。
- 本地化用自写的 L10n 字典，配合 `@AppStorage("uiLanguage")`，不用 String Catalog。

## 关键坑
- 用户的 Mac **只装了 Command Line Tools（macOS SDK 27），没有 Xcode**。SwiftUI 宏（`@State`、`@Observable`、`#Preview`、`@Entry`）会报错 `SwiftUIMacros plugin not found`。
  因此**禁止使用任何宏**。状态改用 `ObservableObject` + `@Published` + `@StateObject` / `@ObservedObject`，持久化设置用 `@AppStorage`，Focused 值用 `FocusedValueKey` 手写。
- 要兼容 Swift 6 工具链的 Swift 5 语言模式。
- 构建所在的 Linux 环境无法编译，所有代码都只能在用户的 Mac 上验证。

## 构建命令
```bash
swift run
./build_app.sh      # build/MacEditor.app
./build_dmg.sh      # dist/MacEditor-1.0.0.dmg
xattr -dr com.apple.quarantine /Applications/MacEditor.app   # 应用为 ad-hoc 签名
```

- 2026-10-21：改进文本编码检测（BOM / 严格 UTF-8 / GB18030 启发式，禁止有损 UTF-8 回退导致中文 CSV 乱码）；状态栏可点选编码重新解码；`.csv`/`.tsv` 映射为纯文本；工作区 FSEvents 自动刷新；⇧⌘F 在工作区文件夹中查找。
- 2026-10-21：完善编辑器功能：多光标/列选择（⌥点击、⌥拖拽、⌃⇧↑↓、⌘D）、缩进折叠（行号栏 ▾/▸）、大纲面板、不可见字符与缩进参考线、磁盘文件变更提示、查找匹配计数、强化“在文件夹中查找”（正则/跳转到行）。
- 2026-10-29：在 `fix/csv-encoding-and-workspace` 分支上实机验证并修复（环境终于有 Xcode Command Line Tools 可编译，不再是盲改）：
  - `NSLayoutManager.setNotShownAttribute` 不存在 `forGlyphRange:` 重载（只有单 glyph 的 `forGlyphAt:`），代码折叠完全无法编译；改成逐 glyph 调用。
  - `gbkByteDensity` 的 UTF-8 识别只认 2 字节序列，不认 3 字节（中文 CJK 常用），导致纯 UTF-8 中文文本被误判成 GBK 密度超标、错误地用 GB18030 解码出乱码——和这个分支本来要修的问题方向正好相反。补上 3/4 字节 UTF-8 序列识别。
  - 外部文件变更监听没有接到保存事件：`EditorUIState.noteDocumentSaved` 声明了却没人调用，导致每次 ⌘S 保存都会被自己的 FSEvents 监听误判成“文件被外部修改”。改成 `TextDocument.fileWrapper` 发 `.documentWillWrite` 通知，各窗口监听后静音。
  - 同一处顺带修了第二个问题：NSDocument 原子保存会换 inode，旧的 kqueue fd 监听保存后就失效，之后的外部修改再也检测不到；保存完 0.5 秒后重新 `watch(url:)`。
  - `FSEventStreamScheduleWithRunLoop` 在 macOS 13 已废弃，换成 `FSEventStreamSetDispatchQueue`。
  - 新增 `Tests/MacEditorTests`（Swift Testing，`import Testing`，不是 XCTest——纯 Command Line Tools 环境没有 XCTest.framework）覆盖折叠、大纲、查找计数、编码探测、字数统计、语言识别，`swift test` 34 个全过。
  - 用 `swift build` / `./build_app.sh` release 构建，实机 `open` 跑过，进程稳定、无崩溃日志；GUI 截图和辅助功能权限在当前会话不可用，用单元测试代替视觉验收。
