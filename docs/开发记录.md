# MacEditor 开发记录

## 用户需求
- 原生 macOS 编辑器，可以编辑代码、Markdown 和纯文本。
- 语法高亮是重点需求（多语言、深浅色配色、增量高亮）。
- 界面语言可以在中文和英文之间切换，切换后立即生效。
- 界面要精致：参考 Nova、Zed、VS Code 的现代风格，内置多套主题。
- 提供 dmg 安装包。
- 源码在 GitHub 公开（Aidan-996/MacEditor）。

## 技术选型
- 用 Swift Package（可执行 target）组织项目，**不使用 Xcode 工程**。用 `swift build` 构建，再用脚本打包 .app 和 dmg。
- 界面用 SwiftUI（DocumentGroup、Settings、Commands），编辑器核心是通过 NSViewRepresentable 包装的 AppKit NSTextView（TextKit 1）。
- 行号栏用 NSRulerView；Markdown 预览用 WKWebView 加内置的 Markdown→HTML 转换器。
- 语法高亮基于正则，先高亮当前行，再防抖做全量高亮。
- 本地化用自写的 L10n 字典，配合 `@AppStorage("uiLanguage")`，不用 String Catalog。

## 关键坑
- 用户的 Mac **只装了 Command Line Tools（macOS SDK 27），没有 Xcode**。SwiftUI 宏（`@State`、`@Observable`、`#Preview`、`@Entry`）会报错 `SwiftUIMacros plugin not found`。
  因此**禁止使用任何宏**。状态改用 `ObservableObject` + `@Published` + `@StateObject` / `@ObservedObject`，持久化设置用 `@AppStorage`，Focused 值用 `FocusedValueKey` 手写。
- 要兼容 Swift 6 工具链的 Swift 5 语言模式。
- 构建所在的 Linux 环境无法编译，所有代码都只能在用户的 Mac 上验证。

## 构建命令
```bash
swift run
./build_app.sh      # build/MacEditor.app
./build_dmg.sh      # dist/MacEditor-1.0.0.dmg
xattr -dr com.apple.quarantine /Applications/MacEditor.app   # 应用为 ad-hoc 签名
```
